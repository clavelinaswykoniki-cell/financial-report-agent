# Project

本仓库是本地金融/投研训练工具集合，重点服务用户的只读研究、报告生成、风险观察和学习训练。

## 当前重点

`scripts/511130_live_monitor` 提供 511130 a 值只读监控和团队看板：

- 默认 dashboard / Docker / Railway 自动刷新间隔为 3 秒。
- 当前 a 与飞书阈值预警锁定东方财富严格实时快照。
- 保留 3 秒行情同步、30 秒新鲜度、缺利息 fail-closed 规则。
- 线上看板为内部观察用途，不下单，不连接交易接口。

`research_training_daily` 提供科技/AI/加密投研训练日报：

- 每天 08:30 生成 `2股 + 1币` 深读训练。
- 同时输出 `5股 + 3币` 观察名单和排序榜单。
- 核心股票/币池可持续新增、移除和复盘。
- 每小时检查新币上市相关信息，覆盖官方公告和非官方早期信号。

所有结果仅用于训练和研究，不自动下单，不构成投资建议。
